Acerca del proyecto

Esta aplicación web fue desarrollada utilizando Python y el framework Flask.

El proyecto tiene como finalidad promover y facilitar la participación en actividades deportivas escolares, fomentando una vida activa y saludable entre los estudiantes.

La aplicación permite presentar información relacionada con las actividades deportivas de una manera sencilla, organizada y fácil de utilizar.
